# Data directory

`derived/` contains aggregate results that do not identify individual students. These files support inspection of the reported results without exposing participant-level educational records.

`private/` is reserved for restricted local inputs. Git ignores every file in that directory except its README. Do not commit raw surveys, assignments, linkage files, names, email addresses, timestamps, verbatim responses, hashing salts, or pseudonymous participant-level datasets.

The aggregate tables are descriptive research outputs and should not be interpreted as a replacement for the protected source records.
